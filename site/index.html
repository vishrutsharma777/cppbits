How it works. Clang 22 and LLD, compiled to WebAssembly, run on your machine. Your code is compiled with a hidden test program that checks it against a reference.

Undefined behaviour such as signed overflow, shifting by 32 or more, or an out-of-range float-to-int conversion stops the program with a runtime error, the same idea as -fsanitize=undefined.

The first visit downloads about 27 MB; later visits load from your browser's cache. Progress and your code are saved in this browser only.
